jQuery is a JavaScript library that simplifies:

DOM manipulation
Event handling
AJAX/API calls
Animations
Form handling
Traversing HTML elements
Working with browser events


jQuery Selectors

Selectors are one of the most important concepts.

ID selector
$("#username")

Class selector
$(".user")

Element selector
$("button")

Attribute selector
$("input[type='text']")

Universal Selector 
$("*")

Extract text from input
const name = $('#txtName').val();
Assign value
$('#name').text("rock");
